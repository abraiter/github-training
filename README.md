# GitHub Training Repository

This repository is used for a beginner Git and GitHub training for criminal justice researchers.

The data and examples in this repository are fake and are for training purposes only.

## Repository Structure

- `analysis/`
  - `01_descriptive_stats.R` — simple descriptive statistics
  - `02_simple_model.R` — fits a simple linear regression model
- `data/`
  - `example_data.csv` — fake criminal justice training data
- `docs/`
  - `research_notes.md` — example project documentation and research decisions
- `practice/`
  - `practice.txt` — file used for Git and collaboration exercises

## Training Goals

Participants will practice how to:

- Navigate GitHub
- Clone a repository
- View file changes
- Stage and commit changes
- Push changes to GitHub
- Pull changes from GitHub
- Collaborate with others
- View Git history
- Restore earlier versions of files

## Important

Do not use real or confidential research data in this repository.

For real research projects, sensitive or restricted data should be stored only in approved locations and excluded from GitHub.
